# Operación `migrate`

| Entorno | Invocación |
|---|---|
| Claude Code | `/jintia-skill` |
| Codex / OpenAI | `$jintia-skill` |
| CLI directa | `jintia migrate` |

Archiva de forma recuperable el contenido actual de una semana antes de una
reestructuración:

```bash
node "<skill-root>/bin/jintia.js" migrate semanas/semana-08
```
